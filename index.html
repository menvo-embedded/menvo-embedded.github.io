BLE Wireless Sensor Network with Failover

Implemented and tested Gateway GATT server and Sensor client firmware. Validated a direct-to-relay recovery path on three physical ESP32 boards.

Implemented

Service discovery, packed 10-byte data format, GATT Write With Response, callback-to-loop queueing, sequence tracking, and Serial CSV logs.

VerilogVivadoZynq-7000AXI4-Lite

Pipelined AES-128 Accelerator on Zynq

Designed iterative and 10-stage pipelined AES-128 cores, then completed the Vivado flow and integrated the accelerator with the ARM Cortex-A9 processing system.

INR0R1R2R3R4R5R6R7R8R9OUT
Vivado workflow

RTL and testbench, behavioral simulation, synthesis, implementation, timing checks, bitstream generation, hardware export, and on-board validation.

Measured scope

FIPS-197 test vectors verified. The pipelined core accepts one 128-bit block per cycle, corresponding to 12.8 Gbps at 100 MHz in RTL simulation.

What I can explain

  • Latency versus throughput in iterative and pipelined cores
  • RTL simulation results versus board-level behavior
  • AXI4-Lite register access from a C driver
  • Vivado RTL versus HLS implementation trade-offs
